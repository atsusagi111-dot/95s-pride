# 本番切り替え手順書(Vercel + GAS → Cloudflare)

切り替え予定: 2026年11月19日(木)12時ごろ。告知は3日前(11/16)と前日(11/18)。
この手順書は、実行する前にユーザー本人の合図を取ってから進める。

## 前提(切り替え前の状態)

- 旧サイト(Vercel)と GAS が本番。会員はここでログインし、新しい回答は GAS がお礼メールを送る
- 検証サイト(Cloudflare)は同じ回答シートを10分おきに読み、D1 へ取り込んでいる。お礼メールは `THANKS_MAIL_SINCE`(11/19 12:00)まで送らない
- 旧サイトでパスワードを設定した人は、D1 にまだ入っていない可能性がある(切り替え時に取り込む)

## 切り替え当日の手順

1. **直前の確認**
   - 検証サイトのトップ、メンバー、管理画面が開くこと
   - GitHub Actions が最新で成功していること
2. **「ログイン管理」シートの確認。** 新しく「停止」にされた人がいないか見る。いれば管理画面で停止する
3. **パスワードの最終取り込み**
   - D1 の会員メールアドレス一覧を取り出す
   - `node scripts/export-password-hashes.mjs ../.env.local <メール一覧> <出力SQL>` で GAS から取り出す
   - 出力 SQL を D1 に当てる(未設定の人だけに入る)
   - 作業ファイルは使い終わったらすぐ削除する
4. **お礼メールの担当を入れ替える(ここが重要。順番を守る)**
   1. ユーザーに、Apps Script の「トリガー」から `onProfileFormSubmit` のトリガーを削除してもらう(GAS の送信が止まる)
   2. 止めた時刻を確認する
   3. `wrangler.jsonc` の `THANKS_MAIL_SINCE` を、その時刻にして push(自動公開)
5. **OGP の URL を新URLにする。** `index.html` の `og:url` と `og:image` を新URLに直して push
6. **旧サイトを転送に切り替える**
   - 旧 `vercel.json` を控える(戻すとき用)
   - `cutover/vercel.redirect.json` の内容で `vercel.json` を置き換える
   - `vercel --prod` で公開する。転送は 307(一時)にしてあり、ブラウザに覚えられないので、戻せる
7. **動作確認**
   - 旧URLを開くと、新URLに移ること
   - 新URLで、ログイン、会員限定の一覧、確認コードのメールが動くこと
8. **告知(完了)を流す。** `announcement.md` の「切り替え当日」を使う

## 戻す手順(問題が出たとき)

1. `vercel.json` を控えのものに戻して `vercel --prod`(旧サイトが復活する)
2. GAS のトリガーを再登録する(Apps Script で `setupTrigger()` を実行)
3. `THANKS_MAIL_SINCE` を先の日付(例: 2027-01-01)にして push
4. 会員に「一時的に旧URLへ戻した」と知らせる

## 切り替えの2週間後(旧構成の停止)

- 11月19日の2週間後(12月3日ごろ)に、次を確認してから止める
  - 旧URLへのアクセスがほぼ無いこと
  - 検証サイト(新URL)で、ログインのトラブル報告が無いこと
- 止めるもの: Vercel のプロジェクト、GAS のウェブアプリのデプロイ、GAS のスクリプトプロパティ(パスワードの保存先)
- 止める前に、スプレッドシートと GAS のコードのバックアップを取る
- アーキテクチャ資料(`アーキテクチャ/*.md`)と `README.md` を、新構成に書き直す

## 気をつけること

- 会員は、新URLで **最初の1回だけ再ログインが必要**(Cookie がURLごとに別のため)。告知に書いてある
- 切り替え後も、フォームの回答先は変わらない(同じスプレッドシートを読み続ける)
- 切り替え後は、新しい回答が10分以内にメンバーページに載る(旧サイトはシートを毎回読むので、すぐ載っていた)

## 2026-11-15 実施結果

- 切り替えを前倒しで実施した(ユーザーの指示)
- 旧URLは、最初は307転送にしたが、同日中に「新サイトはこちら」の案内ページに変更した
  - 案内ページ: `cloudflare/cutover/old-site-notice.html`(Vercel の build で `dist/index.html` にコピーして配信)
  - 開いたページに応じて、新サイトの同じページへのリンクを出す(`/members` → 新サイトの `/members`)
  - `.vercelignore` で旧API(`api/`)を公開から外した。旧サイトからは、ログインや会員情報は取れない
- 転送設定の控え: `vercel.redirect.json`、元の設定: `vercel.original.json`(戻すときに使う)
- お礼メールは GAS が送り続けている。新サイトは `THANKS_MAIL_SINCE` を先の日付にして送らない。GAS のトリガーを削除したら、その時刻に更新する
