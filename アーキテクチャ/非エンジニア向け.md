# 95s PRIDE サイトのしくみ(非エンジニア向け)

プログラミングを知らなくても読めるように、サイトの裏側をまとめました。
技術的な詳細は [エンジニア向け.md](エンジニア向け.md) にあります。

2026年11月に、サイトの土台を新しくしました。URLは **https://95s-pride.inquiry-router.workers.dev** です。
プロフィールアンケートも、Googleフォームをやめて、サイトの中の専用ページ(**/survey**)に引っ越しました。
旧URL(95s-pride.vercel.app)を開くと、「新しいサイトはこちら」の案内ページが出ます。

## このシステムでできること

1. **公式サイトを見る**: だれでも見られます。理念、お知らせ、個人活動、参加案内などを載せています。
2. **メンバー紹介を見る**: 一部のメンバーのプロフィールは、だれでも見られます。
3. **会員限定のページを見る**: プロフィールアンケートに回答した人だけが、ログインして見られます。
4. **お礼メールを送る**: アンケートに回答した人へ、自動でお礼のメールを送ります。
5. **運営管理画面で管理する**: 運営メンバーが、公開する人やログインの停止などを、画面から変えられます。

## 全体像

お店にたとえると、次のような関係です。

```
  お客さん(サイトを見る人)
     │
     ▼
  お店(公式サイト)         …… 見に来た人の対応をする。事務所の機能も入っている
     │
     ├─▶ 台帳(データベース)  …… 会員やプロフィールを保管する
     └─▶ 郵便(メール)        …… 確認コードやお礼を届ける

  アンケートの回答(サイト内の /survey) ─▶ そのまま台帳に保存
```

お客さんが台帳を直接見ることはできません。必ずお店を通るので、見せてよい情報だけを表示できます。
アンケートの回答は、サイトの中のページから直接台帳に入ります。サイトの表示は、台帳(データベース)の内容が元になります。昔のGoogleフォームの回答は、記録として旧スプレッドシートに残っています(新しい回答は入りません)。

## 情報はどこにある?

| 情報 | 置き場所 | 変更するには |
|---|---|---|
| 理念、お知らせ、個人活動、参加案内 | サイト本体 | サイト担当者に依頼 |
| メンバーのプロフィール | アンケートの回答(そのまま台帳に保存される) | 回答を新しく送り直す(最新のものが表示される) |
| プロフィールの写真 | アンケートの「プロフィール写真(任意)」(送信のときに、自動で正方形に整える) | アンケートを送り直す。運営が管理画面で、送られた写真を削除することもできる |
| ログイン後に出す紹介カード | 台帳 | 運営管理画面で編集 |
| 公開する人、ログインの停止 | 台帳 | 運営管理画面で変更 |

## プロフィールの見え方

アンケートの回答が、そのままプロフィールになります。

- **だれでも見られる人(公開)**: 運営管理画面で「公開」にした人。
- **会員だけが見られる人(会員限定)**: ログインした会員だけが見られます。新しく回答した人は、最初はこちらです。
- **出さない人(非表示)**: どこにも出しません。
- **見せない項目**: メールアドレス、電話番号、住所、本名などは、だれにも表示しません。
- **SNS・リンク**: アンケートに入れたX、Instagram、YouTube、TikTok、HPなどが、名前の下に丸いアイコンで並びます。押すと、そのページが新しいタブで開きます。入れなかったSNSのアイコンは出ません。
- **写真**: アンケートの「プロフィール写真(任意)」で送られた写真を、正方形に整えて出します。写真を送らなかった人には、共通の人型のアイコンを出します。写真は、アンケートに回答したときにだけ送れます。会員が、あとから自分で変えることはできません。

同じ人が2回回答したときは、新しい回答だけを表示します。古い回答は、データとして残ります。
2回目の回答に写真が入っていれば、写真が差し替わります。写真が入っていなければ、前の写真がそのまま残ります。

## メンバーページの使い方

### はじめての人(パスワードの設定)

1. メンバーページの「はじめての方・パスワードを忘れた方」を押す
2. アンケートに回答したときのメールアドレスを入力する
3. メールに届いた6桁の確認コードと、新しいパスワード(8文字以上)を入力する
4. パスワードが設定され、そのまま会員限定のページが開く

アンケートに回答していないメールアドレスでは設定できません。画面にその旨が表示されます。
アンケートに回答すると、すぐにサイトに反映されます。

### 2回目から

メールアドレスとパスワードでログインします。
一度ログインすると、同じ端末・同じブラウザでは30日間そのまま見られます。

### パスワードを忘れたとき

「はじめての方」と同じ手順で、新しいパスワードを設定し直せます。

## アンケートの答え方(回答する人向け)

1. サイトの **/survey**(メンバーページの「プロフィール回答はこちら」)を開く
2. メールアドレスを入力すると、6桁の確認コードがメールで届く
3. コードを入力すると、アンケートが始まる(他の人がなりすまして回答できないようにするための確認です)
4. 質問に答える。画面の下に「あと何項目か」を示すバーが出る。必須の項目をすべて入れたら「送信する」を押す

Googleアカウントのログインは要りません。写真(任意)も、そのまま選んで送れます。

## お礼メールの流れ

1. アンケートが送信される
2. すぐに、サイトが回答を保存する
3. 質問19「なんでもお悩み相談」の特典を受け取るかどうかを確認する
4. 「受け取る」人には日程調整の案内を、「受け取らない」人にはお礼を自動で送る。どちらのメールにも、メンバーページのリンクを入れている

同じ人に同じメールが二重に届かないようになっています。送信に失敗したときは、10分おきに自動でやり直します(1日たったらあきらめます)。

## 運営管理画面

運営メンバーとしてメンバーページでログインしたあと、**https://95s-pride.inquiry-router.workers.dev/admin** を開きます。運営として登録された人だけが使えます。

### 画面の見方

メンバーの一覧には、次の項目があります。

| 項目 | 意味 |
|---|---|
| 名前 / メール / 回答日 | アンケートの回答の情報。メールが「(メールなし)」の回答は、会員と結び付けられません |
| 公開範囲 | 「公開」(だれでも見られる)、「会員限定」(ログインした人だけ)、「非表示」(どこにも出さない)。選ぶとすぐに変わります |
| 写真 | 運営が設定した写真のファイルの場所(通常は空)。アンケートで写真が送られた人には「アンケートで送られた写真あり」と出て、その写真が優先されます。不適切な写真は、ここの「送られた写真を削除」で消せます |
| ログインの状態 | その人が、ログインできるかの状態(下の表) |
| メモ | 運営用のメモ。会員には見えません |

「ログインの状態」の欄の見方です。管理画面にも、同じ説明が出ています。

| 表示 | 意味 |
|---|---|
| **ログインできる**(緑) | パスワードを決めた人。いつでもログインできます |
| **まだ使い始めていない**(灰色) | アンケートには回答したが、まだパスワードを決めていない人。問題ではありません |
| **ログイン停止中**(赤) | 運営が止めた人。「再開する」を押すと戻ります |
| **ログインできません**(灰色) | メールアドレスのない回答。会員としては扱いません |
| **停止する** ボタン | 押すと、確認が出ます。「OK」を押すと、その人は次にページを開いたときから見られなくなります。あとで「再開する」で戻せます |

この欄は、「いま、サイトにログインしている」という意味ではありません。パスワードを決めたかどうかを表しています。

### この画面を使える人

運営として登録された人だけが、この画面を使えます。登録されていない人は、ログインしていても開けません。
権限は2段階です。画面の下の「この画面を使える人」で、だれがどの権限か、だれに招待されたかを確認できます。

| 権限 | だれか | できること |
|---|---|---|
| **オーナー** | あっちゃん、ワケトン | すべての操作。**運営メンバーの招待と解除**もできる |
| **管理者** | オーナーに招待された人 | ログインの停止・再開、公開範囲、項目の見せる隠す、紹介カード。**招待と解除はできない** |

- 団体の共用メールアドレス(95spride.official@gmail.com)は、管理の操作ができません。登録も招待もできない設定です
- 運営の人は、この画面から停止できません(自分たちを締め出す事故を防ぐためです)
- 別のサイトから送られた操作は、受け付けません
- 画面の一番下の「操作の記録」に、いつ、だれが、何をしたかが残ります

#### 運営メンバーを招待する(オーナーのみ)

1. 画面の下の「この画面を使える人」で、招待する人のメールアドレスを入れて「招待する」を押す
2. 確認が出るので、「OK」を押す
3. その人に、案内のメールが届く
4. その人は、メンバーページの「はじめての方・パスワードを忘れた方」から、パスワードを決めてログインし、`/admin` を開く

間違えて招待したり、運営を外したいときは、同じ一覧の「外す」を押します。外された人は、この画面を使えなくなります(メンバーとしてのログインは、そのままです)。

### 運営ができること


| やりたいこと | 方法 |
|---|---|
| 特定の人をだれでも見られるようにする | 公開範囲を「公開」にする |
| 特定の人のログインを止める | 「ログインの状態」欄の「停止する」を押す |
| 止めた人を戻す | 「再開する」を押す |
| プロフィールの項目を見せる・隠す | 画面の下の「設問の公開設定」で、チェックを入れ外しする |
| ログイン後の紹介カードを追加・修正する | 画面の下の「紹介カード」で編集して「保存」 |

画面で変えたことは、すぐにサイトに反映されます。

## サイト担当者に依頼すること

- お知らせ、イベント、個人活動、協賛企業の追加や変更
- 運営が設定する写真(アンケートを使わない特別な写真)の追加
- アンケートに回答していない人の会員登録、オーナーの追加・変更
- アンケートの設問の追加・変更
- サイトの文章、色、レイアウトの変更
- 確認コードやお礼メールの文面の変更

サイト担当者が変更して GitHub に上げると、テストを通ったあと、自動でサイトに反映されます。

## 安全のためのしくみ

- パスワードは元に戻せない形に変換して保存します。運営メンバーにも見えません。
- ログインを続けて10回まちがえると、15分間ログインできなくなります。
- 確認コードは10分で使えなくなります。5回まちがえても使えなくなります。
- 確認コードのメールは、同じ人へ短い間に何度も送れないように制限しています。
- 「停止」にした人は、次にページを開いたときから見られなくなります。
- メールアドレスや電話番号などの連絡先は、サイトに出しません。
- メンバーページと管理画面は、検索結果に表示しない設定にしています。
- 運営管理画面には、運営として登録された人しか入れません。
- データは、前の状態に戻せる仕組み(7日間)があります。

## 気をつけること

- **回答の編集はできません**: 内容を直したい人には、アンケートをもう一度送ってもらってください。新しい回答が表示されます。
- **アンケートの設問を変える前に、サイト担当者に相談する**: 質問1・2・3・19の文言を変えると、表示やお礼メールに影響します。設問の追加・変更は、サイトの設計(データベース)の変更になります。
- **旧スプレッドシートの共有範囲を広げない**: 昔の回答が入っていて、個人情報を含みます。
- **コードが届かないときは迷惑メールフォルダを確認する**: 見つからなければ、1分ほど待って送り直してください。短い間に何度も送ると、しばらく送れなくなります。
- **1995年生まれかどうかは確認していません**: アンケートに回答すればだれでも会員になれます。会員限定のページには、会員全員に見えてよい内容だけを載せてください。
- **写真は、アンケートを送り直したときに変えます**: 同じメールアドレスで、写真の欄に新しい写真を入れて送ります。公開しているプロフィールの人は、送り直すと「会員限定」に戻るので、運営が「公開」に戻してください。
