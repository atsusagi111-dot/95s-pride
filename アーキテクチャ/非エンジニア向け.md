# 95s PRIDE サイトのしくみ(非エンジニア向け)

プログラミングを知らなくても読めるように、サイトの裏側をまとめました。
技術的な詳細は [エンジニア向け.md](エンジニア向け.md) にあります。

## このシステムでできること

1. **公式サイトを見る**: だれでも見られます。理念、お知らせ、個人活動、参加案内などを載せています。
2. **メンバー紹介を見る**: 一部のメンバーのプロフィールは、だれでも見られます。
3. **会員限定のページを見る**: プロフィールアンケートに回答した人だけが、ログインして見られます。
4. **お礼メールを送る**: アンケートに回答した人へ、自動でお礼のメールを送ります。

## 全体像

お店にたとえると、次のような関係です。

```
  お客さん(サイトを見る人)
     │
     ▼
  お店(公式サイト)         …… 見に来た人の対応をする
     │
     ▼
  事務所(Googleの自動処理) …… 会員かどうかの確認や、メール送信をする
     │
     ├─▶ 台帳(スプレッドシート)…… アンケートの回答や会員の情報を保管する
     └─▶ 郵便(メール)          …… 確認コードやお礼を届ける
```

お客さんが台帳を直接見ることはできません。
必ずお店と事務所を通るので、見せてよい情報だけを表示できます。

## 情報はどこにある?

| 情報 | 置き場所 | 変更するには |
|---|---|---|
| 理念、お知らせ、個人活動、参加案内 | サイト本体 | サイト担当者に依頼 |
| メンバーのプロフィール | スプレッドシートの回答シート(アンケートの回答) | 本人がアンケートの回答を編集する |
| プロフィールの写真 | サイト本体 | サイト担当者に依頼 |
| ログイン後に出す紹介カード | スプレッドシートの「メンバー掲載」 | シートを直接編集 |
| ログインの許可・停止 | スプレッドシートの「ログイン管理」 | シートを直接編集 |

## プロフィールの見え方

アンケートの回答が、そのままプロフィールになります。

- **だれでも見られる人**: 運営が選んだ一部の人。サイト担当者がプログラムの中で決めています。
- **それ以外の人**: ログインした会員だけが見られます。
- **見せない項目**: メールアドレス、電話番号、住所、本名などは、だれにも表示しません。
- **写真**: 写真が登録されていない人には、共通の人型の画像を出します。

## メンバーページの使い方

### はじめての人(パスワードの設定)

1. メンバーページの「はじめての方・パスワードを忘れた方」を押す
2. アンケートに回答したときのメールアドレスを入力する
3. メールに届いた6桁の確認コードと、新しいパスワード(8文字以上)を入力する
4. パスワードが設定され、そのまま会員限定のページが開く

アンケートに回答していないメールアドレスでは設定できません。画面にその旨が表示されます。

### 2回目から

メールアドレスとパスワードでログインします。
一度ログインすると、同じ端末・同じブラウザでは30日間そのまま見られます。

### パスワードを忘れたとき

「はじめての方」と同じ手順で、新しいパスワードを設定し直せます。

## お礼メールの流れ

1. アンケートが送信される
2. 質問19「なんでもお悩み相談」の特典を受け取るかどうかを確認する
3. 「受け取る」人には日程調整の案内を、「受け取らない」人にはお礼を自動で送る

同じ人に同じメールが二重に届かないようになっています。

## 運営メンバーができること

| やりたいこと | 方法 |
|---|---|
| 特定の人のログインを止める | 「ログイン管理」シートに、その人のメールアドレスを書き、状態を「停止」にする |
| 止めた人を戻す | 状態を「許可」にするか、その行を消す |
| アンケート未回答の人をログインできるようにする | 「ログイン管理」シートに、メールアドレスと「許可」を書く |
| ログイン後の紹介カードを追加・修正する | 「メンバー掲載」シートを編集する |

シートの変更は、ページを開き直せばすぐ反映されます。

## サイト担当者に依頼すること

- お知らせ、イベント、個人活動、協賛企業の追加や変更
- プロフィール写真の追加や差し替え
- だれでも見られるプロフィールの人の入れ替え
- サイトの文章、色、レイアウトの変更
- 確認コードやお礼メールの文面の変更

変更してから「公開作業」をするまで、サイトには反映されません。

## 安全のためのしくみ

- パスワードは元に戻せない形に変換して保存します。運営メンバーにも見えません。
- ログインを続けて10回まちがえると、15分間ログインできなくなります。
- 確認コードは10分で使えなくなります。5回まちがえても使えなくなります。
- 確認コードのメールは、同じ人へ短い間に何度も送れないように制限しています。
- 「停止」にした人は、次にページを開いたときから見られなくなります。
- メールアドレスや電話番号などの連絡先は、サイトに出しません。
- メンバーページは検索結果に表示しない設定にしています。

## 気をつけること

- **シートの名前を変えない**: 「ログイン管理」「メンバー掲載」の名前が変わると、ログインや表示が動かなくなります。
- **回答シートの行を並べ替えない・途中に行を入れない**: だれでも見られるプロフィールは「何行目か」で決めています。行がずれると、別の人が公開されてしまいます。
- **フォームの設問を変える前に相談する**: メールアドレスや質問1・2・19の文言を変えると、表示やお礼メールに影響します。
- **スプレッドシートの共有範囲を広げない**: 回答シートには個人情報が入っています。
- **コードが届かないときは迷惑メールフォルダを確認する**: 見つからなければ、1分ほど待って送り直してください。短い間に何度も送ると、しばらく送れなくなります。
- **1995年生まれかどうかは確認していません**: アンケートに回答すればだれでも会員になれます。会員限定のページには、会員全員に見えてよい内容だけを載せてください。

## 言葉の説明

| 言葉 | 意味 |
|---|---|
| アーキテクチャ | システムの設計図 |
| 確認コード | 本人確認のためにメールで届く、1回限りの6桁の番号 |
| ログイン | 会員であることを確認して、ページに入ること |
| 公開作業 | 変更した内容を、実際のサイトに反映すること |
| GitHub | プログラムを保管・共有する場所。ここに置いただけではサイトは変わらない |
